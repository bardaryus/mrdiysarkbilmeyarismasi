# Melody Match

ben bir müzik tahmin sitesi oluşturmanı istiyorum. mesela anlık türkiyede en çok dinlenen sportifyda en çok dinlenen 1000 şarkıdan falan oluşabilir site. Şarkı çalacak. ofiste arkadaşlarımıla yarışacağız. Şarkıyı ilk bilen yani adını doğru yazan kazanacak. oda oluşturacağım diğer kişiler odama katılacak. şarkı çaldığı an ilk şarkı adını doğru yazan puan kazanacak. atıyorum xx puana ulaşan kazanacak. teması spotifya benzer olabilir.
